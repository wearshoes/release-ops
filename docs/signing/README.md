# Signing Extensions

Signing extensions attach signing policy and Secret roles to selected build units. They do not own versions, repositories, or release destinations.

| Extension | Purpose |
| --- | --- |
| [`android-keystore`](android-keystore.md) | Android keystore signing |
| [`apple-codesign`](apple-codesign.md) | Apple codesign and provisioning |
| [`generic-command`](generic-command.md) | Explicit structured signing command |
